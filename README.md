# Kriptografi Klasik Flask

Struktur awal proyek aplikasi web simulasi kriptografi klasik.

## Struktur Folder

- `app/` - package utama aplikasi Flask
- `app/algorithms/` - modul Caesar, Vigenere, Affine, Hill, dan Playfair
- `app/routes/` - blueprint route aplikasi
- `app/services/` - layanan seperti history dan proses bisnis
- `app/utils/` - helper validasi dan manipulasi teks
- `app/templates/` - template Jinja2
- `app/static/` - aset CSS, JS, dan gambar
- `tests/` - pengujian algoritma
- `instance/` - data lokal seperti history

## Tujuan

Proyek ini disusun agar setiap algoritma bisa ditampilkan langkah per langkah, mudah diuji, dan mudah dijelaskan di laporan.
